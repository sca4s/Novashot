# Novashot

![Built with Three.js](https://img.shields.io/badge/Built%20with-Three.js%20&%20Tailwind-38bdf8?style=for-the-badge)

**Novashot** is a high-octane, browser-based 3D pastel arcade blaster built entirely with vanilla JavaScript, Three.js, and Tailwind CSS. Featuring zero external asset dependencies, spatial frosted glass UI components, a 360° Ranger Avatar Studio, and dynamic day/night world cycles, Novashot delivers an immersive arcade shooter experience directly in your web browser.

---

## ✨ Key Features

* **🎨 360° Ranger Avatar Studio**: Fully customize your character’s gender, outfit cut, skin tone, multi-shade shirt colors, and pant palettes with live 360° inspection and auto-spin controls.
* **👾 Multi-Enemy Visitor Waves**: Fight against customizable waves of Zombies, Alien Ships, Skeletons, Ghosts, and Cosmic Entities with adjustable dress palettes and speeds.
* **🌸 5 Distinct World Biomes**: Explore and switch between **Grass**, **Ground**, **Rock**, **Underwater**, and **Sky** biomes complete with procedural 3D scenery, floating bubbles, and fluffy clouds.
* **🎥 6 Cinematic Camera Perspectives**: Switch seamlessly between Classic, Action Close, Top-Down, First-Person, Cinematic, and Fixed Swivel camera modes.
* **🔄 Advanced Mechanics**: Includes portal wall-wrapping, dynamic day/night cycles, enemy magnification (2.5× optical zoom), and manual core reload options for Fixed Swivel mode.
* **🔊 Built-in Web Audio Synthesizer**: Immersive procedural sound effects for laser blasts, explosions, fruit pickups, reloads, and UI ticks with zero external audio or image files required.

## 🎮 Controls & Hardware Modes

Novashot supports both **Smartphone / Tablet (Touch)** and **Laptop / Desktop (Keyboard)** configurations:

### Desktop Controls (Keyboard & Mouse)
* **`←` / `ôtels` (`A` / `D`)**: Move left and right (or swivel/rotate aim in Fixed Swivel mode).
* **`↑` or `Space`**: Fire blaster energy bolt.
* **`P`**: Open/Close Pause & World Studio deck.
* **`C`**: Cycle through camera perspectives.
* **`M`**: Toggle 2.5× Enemy Magnification zoom.
* **`R`**: Manual Core Reload (essential in Fixed Swivel mode before the 15s timer expires).
* **`E`**: Switch active visitor enemy type.
* **`B`**: Switch world biome.

---

## 🚀 Getting Started

Simply open the `Novashot.html` file in any modern web browser with WebGL support, select your hardware control mode, customize your Ranger in the 360° Avatar Studio, and click **Initiate Novashot** to play!
